# 1.1 intent-capture：質問と回答

最初の依頼文 `[desc]`：ネコが遊べるアプリを作りたい。YouTube のネコ動画は、ネコが触ると止まる・スキップする・別の動画のリンクに触れてしまう。ネコが熱中できるようにして、ネコの体験を良くしたい。
プラン `[scope]`：`poc`

| ID | 質問 | 回答 |
|---|---|---|
| Q1 | 誰のためのアプリか | B. 同じ悩みを持つ一般の飼い主にも使ってもらいたい |
| Q2 | 何ができたら成功か（複数選択） | A. 1 回 5 分以上遊び続けられる／B. 触っても停止・スキップ・画面移動が一度も起きない／C. YouTube より夢中になっていると感じられる |
| Q3 | 関係者と、決める人 | B. 家族など身近な人の意見も聞くが、決めるのは自分 |
| Q4 | PoC でやらないこと（複数選択） | C. 遊んだ時間などの記録・統計（→ Q8 で見直し） |
| Q5 | PoC は誰に試してもらうか | B. 知り合いなど一部の飼い主にも試してもらう |
| Q6 | 登録・ログイン・課金を含めるか | B. 登録・ログインだけ含める |
| Q7 | 「YouTube より夢中」の判断方法 | A. 同じネコで YouTube とアプリを試し、遊び続けた時間を比べる |
| Q8 | 遊んだ時間の測り方（Q4 と Q2・Q7 の食い違い） | C. 記録・統計も PoC に含める（Q4 を見直す） |
| Q9 | 家族が重視していること（複数選択） | A. ネコが楽しそうに夢中で遊べる／B. 端末やネコの安全／X. ネコ一匹で遊んでほしい |
| Q10 | 試してもらう飼い主の期待（複数選択） | B. ネコが今より夢中になれる新しい遊び |
| Q11 | 感想の集め方（複数選択） | B. 簡単なアンケートを用意する |
| Q12 | 何匹で比べ、何匹で上回れば合格か | A. 自分のネコ 1 匹で比べ、アプリの方が長ければ合格 |
| Q13 | 1 匹につき何回比べるか | D. まだ決めていない（→ Q15） |
| Q14 | 遊んだ時間を誰が測り、どう報告するか | A. アプリの時間はアプリの記録、YouTube の時間は各飼い主が測ってアンケート（Q11）で報告 |
| Q15 | 自分のネコ 1 匹で何回比べるか | B. 3 回ずつ試し、平均の時間で比べる |

- まとめの確認：Looks correct
- 決まっていない点「1 匹につき何回比べるか」`[assumption]`：B. 追加の質問にする（→ Q9〜Q15）
