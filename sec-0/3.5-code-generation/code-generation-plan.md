# 3.5 code-generation：書く順番の計画

入力：要件（FR1〜FR7、NFR1〜NFR6）と、2.5 の画面・動き・色・アクセシビリティ。ユーザーストーリー・ユニット分割・機能設計はこのプランにないため、各ステップを要件の ID に対応させる。Supabase の URL と公開キーは環境変数から読み、コードに書かない。

## ステップ（17 個、すべて完了）

| Step | 中身 |
|---|---|
| 1 | プロジェクトの骨組み（Expo SDK・TypeScript・expo-router・react-native-svg など） |
| 2 | テストの実行環境（jest-expo、Testing Library、モック） |
| 3 | Supabase のテーブル定義 `records`（行ごとのアクセス制限つき） |
| 4 | データの形のテスト（直近 3 回の平均、時間の表示、制限の文） |
| 5 | 保存とやりとり（接続、登録・ログイン・ログアウト、記録、送り直し、設定） |
| 6 | 保存とやりとりのテスト |
| 7 | 遊び 1 回の状態と時間の数え方（`playSession`） |
| 8 | 「α」の判定（`alphaGesture`：指ごとの軌跡、一筆の α の形） |
| 9 | 遊びのきまりのテスト |
| 10 | サーバーは作らず、Supabase の認証とテーブルを窓口にする |
| 11 | 窓口のテストは Step 4・6 で代える（実物の Supabase につなぐテストはしない） |
| 12 | 色・文字・間隔と、飼い主の画面（S1・S1b・S2・S2a・S6） |
| 13 | ネコの画面（S3 遊び画面、S4 飼い主メニュー、S5 結果） |
| 14 | 短い音のファイルを作るスクリプト |
| 15 | 画面のテスト |
| 16 | 実行の設定と型の確かめ |
| 17 | code-summary.md のまとめ |
