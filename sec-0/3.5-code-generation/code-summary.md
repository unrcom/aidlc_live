# 3.5 code-generation：書いたファイルと主な判断

## 使ったもの

Expo SDK 58（React Native 0.88.1、React 19.3、TypeScript 6.0）、expo-router、Supabase（認証と `records` テーブル）、react-native-svg、expo-keep-awake、expo-screen-orientation、expo-audio、AsyncStorage、NetInfo。テストは Jest（jest-expo）と Testing Library。

## 主な判断

- **遊びの時間**：自動で終わるまでの起点は、待機中は開始時刻、遊び中は最後のタッチ、メニューを閉じたあとは閉じた時刻。メニュー中のネコのタッチは遊んだ時間に数え、10 秒の数えは戻さない。遊んだ日時はネコが最初に触った時刻
- **指が触れている間は自動で終わらない**（計画にない追加）
- **「α」の判定**：指が離れた時点で軌跡を 64 点に並べ直して判定。自分との交差がちょうど 1 回、輪が左回り、輪が全体の 30% 以上、前後のしっぽが 4% 以上、始点と終点が離れている、生の点が 8 点以上。大きさは問わない
- **記録の保存**：まず端末に書いてから送る。通信がなければ「保存待ち」、自動の送り直しが 3 回続けて失敗したら「保存できていない」
- **アカウントの安全（NFR5）**：行ごとのアクセス制限を有効にし、読む・追加・変える・消すのそれぞれで本人の行だけを許す
- **誤操作の防止（NFR1）**：遊び画面と結果画面では、Android の戻るボタンと iOS のスワイプで戻る操作を止める。画面は暗くならず、向きは始まった時点で固定
- **決まっていなかった値**：メモは 200 文字まで、送り直しは 3 回失敗で知らせる、ネズミは 6〜12 秒後に初めて出て、その後 15〜35 秒おき

## テストの結果

- `npx jest __tests__`：16 ファイル・105 件すべて成功
- `npx tsc --noEmit`：誤りなし
- 実物の Supabase につなぐテストはしていない（Step 11）。アプリの起動もこの段階ではしていない

## 計画からの変更

1. `expo-av` が SDK 58 で使えないため `expo-audio` にした
2. 計画にないパッケージを足した（react-dom、babel-preset-expo、jest など）
3. `tsconfig.json` の `types` に `node` を入れた
4. 計画にないファイルを足した（`AuthForm`、`controls`、`TouchSurface`、`toyMotion`、`useToySounds`、`network`、`AppProvider` など）
5. 起動のスクリプトを `expo start --ios` / `--android` にした
6. 案内画面（S2a）の「α」の書き順を、判定と同じ形（右下から左回りの輪を描いて右上へ）にした

## 実機で確かめること

NFR1（5 分以上を 3 回）、NFR2（自動ロック 2 分で 10 分）、NFR3（4 種類の端末）、FR3.1・FR3.4（「α」10 回中 8 回、ネコ 10 分×3 回で 0 回）、読み上げ機能、文字の最大化と色の差、動きと音の速さ・頻度・大きさ、アプリが通しで起動すること。
