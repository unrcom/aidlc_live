# 2.5 refined-mockups：色と部品

新しいアプリなので、既存のデザインシステムはない。iOS と Android の両方に用意する（NFR3）ため、それぞれの標準部品に対応させる。

## 色

| 名前 | 用途 | 値 |
|---|---|---|
| primary | 主要ボタン | #1F5FBF |
| text | 本文 | #1A1A1A |
| error | エラー（必ず文章と印を一緒に出す） | #B3261E |
| play-bg-dark / play-bg-light | 遊び画面の背景 | #14161A / #D9DCE0 |
| toy-blue / toy-yellow | 紐・しっぽ・ネズミ | #3D7BFF / #F2C230 |
| toy-white | 背景が暗いときだけ | #F5F5F5 |
| toy-black | 背景が明るいときだけ | #111111 |
| toy-outline | 明るい背景のときの縁取り | #2A2F38 |
| result-dim | 結果画面の背景と文字 | #1E2024、文字 #B8BCC4 |

獲物の色は、ネコが見分けやすい青と黄色を基本に、暗い背景では白、明るい背景では黒を足す（RF-Q4、承認時の変更依頼）。

## 文字・間隔・部品

- 文字：見出し 24pt、本文 17pt、補足 14pt、結果画面の遊んだ時間 48pt。端末の文字の大きさの設定に合わせる
- 間隔：4・8・16・24・32・48pt。押せる部品は 44×44pt 以上（「ネコを遊ばせる」は高さ 96pt 以上）、間は 8pt 以上
- 部品：主要ボタンは塗りつぶし、2 番目は枠線、選択肢はセグメント、音はスイッチ、確認はアラート／ダイアログ、記録はリスト。遊び場・「α」の判定・飼い主メニューは独自に描く
- 動き：飼い主の画面は 0.3 秒以内、「アニメーションを減らす」がオンなら減らす。遊び画面の動きは遊びそのものなので止めないが、1 秒に 3 回を超えて光らせない
