# 2.5 refined-mockups：動きと操作のきまり

## 1 回の遊びの状態

```
[案内 S2a] --5 秒 / すぐ始める--> [待機]
[待機] --ネコが触る--> [遊び中]
[待機] --決めた秒数触られない--> [終了・記録なし]
[遊び中] --決めた秒数触られない--> [終了・記録あり]
[待機] / [遊び中] --「α」--> [メニュー表示中]
[メニュー表示中] --遊びに戻る / 10 秒操作なし--> 元の状態（メニュー中にネコが触ったなら遊び中）
[メニュー表示中] --遊びを終える--> [終了]（一度でも触られていれば記録あり）
```

| 項目 | 数え方 |
|---|---|
| 遊んだ時間 | ネコが最初に触った時刻から最後に触った時刻まで（FR5.1） |
| 自動で終わるまでの残り | 待機中は始まった時刻から、遊び中は最後に触った時刻から。メニュー中は止め、閉じた時刻から数え直す（FR4.1、FR4.4、FR4.5） |
| メニュー中のネコのタッチ | 後ろの遊びが受け、遊んだ時間と最後に触った時刻に数える。待機中なら「最初に触った」になる（RF-Q5） |
| 数えない操作 | 「α」と認識された指、メニューのボタン |

## 部品ごとのきまり

| 部品 | きまり |
|---|---|
| AlphaGesture（「α」の判定） | 触れているすべての指を 1 本ずつ別々に追い、どれか 1 本の軌跡が一筆の「α」なら認識（RF-Q6）。大きさは問わない（RF-Q3）。ほかの指が触れても判定は続け、そこでは遊びが反応する（FR2.3、FR2.4）。「α」の指はタッチに数えない（FR4.5）。合格基準は 10 回中 8 回以上・ネコ 10 分×3 回で 0 回（FR3.1、FR3.4）。認識したら読み上げる |
| PlayField（遊び場） | 2〜3 本の紐やしっぽが動き、触ると 0.3 秒ほど跳ねて逃げる。ネズミはときどき端から出て横切る。メニュー中は数えだけ止める（RF-Q5）。背景 dark / light で色を変える（RF-Q4）。音のオン・オフ（FR2.6）。タブレット 3 本、スマートフォン 2 本（FR2.1）。向きは始まった時点で固定。背景との明るさの差は 3:1 以上、1 秒に 3 回を超えて光らない |
| OwnerMenu（飼い主メニュー） | 「α」で開き、遊んだ時間と残り秒数を出す。10 秒操作がなければ閉じる（RF-Q2）。後ろでネコが触っても秒数は戻さない。タッチはモーダルではなく、枠の外は後ろの遊びに渡す（RF-Q5）。読み上げのフォーカスはメニュー内に閉じ込め、最初の操作対象は「遊びに戻る」 |
| SaveStatus（保存の状態） | saved「記録しました」、pending「保存待ち」（FR7.1）、failed 印（!）と「保存できていない記録があります」（FR7.3）、retrying「送信中…」（FR7.4）。変わったら読み上げ、色だけに頼らない（NFR6） |
| PlaySettings（遊びの設定） | 自動で終わるまで 30・60・120・300 秒（初期値 30、FR4.2）、音（初期値オン、FR2.6）、背景（初期値 dark、RF-Q4）。端末に保存し、次の遊びから使う |
| RecordList（記録の一覧） | 読み込み中・一覧と平均・1〜2 件（「3 回遊ぶと平均が表示されます」）・0 件・エラーの 5 つの状態（FR6.3）。1 件ずつ「11 月 3 日 20 時 15 分、12 分 30 秒、メモ ミケとトラ」と読み上げる |
| 確認ダイアログ（ログアウト） | 送れていない記録があるときだけ、件数と「この記録は消えます」。最初の操作対象は「やめる」（FR1.3） |
