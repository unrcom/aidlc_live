# 3.6 build-and-test：テストと実機での確認の結果

## 自動テストと組み立て

| 確認 | 結果 |
|---|---|
| `npx tsc --noEmit` | 誤りなし |
| `npx expo export --platform ios --platform android` | 成功（iOS・Android のバンドルが 1 つずつ） |
| `npx jest __tests__`（コード生成の直後） | 16 ファイル・105 件、すべて成功 |
| `npx jest __tests__`（動作確認での変更のすべてのあと） | 18 ファイル・122 件、すべて成功 |

画面のテストは Node 上の Testing Library によるもので、実機の描画やタッチではない。カバレッジは測っていない（poc）。

## 実機での確認（iPad）

自動ロックは、開発用の配信だとどの画面も暗くならないため、本番と同じ配信で確かめた。

| 確認 | 結果 |
|---|---|
| ホーム画面で自動ロックする（2 分） | 2 分で暗くなった |
| 遊び画面で自動ロックしない（NFR2） | 暗くならなかった |
| 結果画面で自動ロックする | 2 分で暗くなった |
| 「α」を 10 回描くと開く（FR3.1、合格は 8 回以上） | 10 回中 9 回。合格 |
| 「α」ではない動きでは開かない（FR3.4 の一部） | 開かなかった |
| 触ると音が出る | 出た |
| 電波がないときの記録が残り、戻ると送られる（FR7.1、FR7.2） | 送られた |
| 遊び画面を 10 分動かす（NFR2、FR3.4） | 暗くならず、メニューが勝手に開くこともホームに戻ることもなかった |
| 組み立てたアプリでの通しの動き（ログイン → ホーム → 遊び → α → 結果 → ホーム） | 動いた |

## 組み立てたアプリ

- `npx expo prebuild` で `ios/` を作り、Xcode の Release で組み立て、`xcrun devicectl` で iPad と iPhone 17 に入れた
- 署名は無料の Apple ID。7 日で起動しなくなるため、預ける前に期限を作り直した（2026-11-12 の夜まで）
- iPhone 15 にも入れようとしたが、端末の準備がうまくいかず、やめた
