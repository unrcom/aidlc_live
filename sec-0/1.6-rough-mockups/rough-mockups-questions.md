# 1.6 rough-mockups：質問と回答

| ID | 質問 | 回答 |
|---|---|---|
| Q1 | ネコの画面に何を映すか | X. 紐・しっぽ・猫じゃらし。たまにネズミ。動き回り、ネコが触ると「ビクッ」と反応する |
| Q2 | 家族の「ネコ一匹で遊んでほしい」の意味 | X. 人が付き添わないという意味。複数のネコが同時に遊べるようにしたい |
| Q3 | 1 回の遊びの終わり方（複数選択） | C. ネコが一定時間（例：30 秒）触らなかったら自動で終わる |
| Q4 | 遊ばせる端末（複数選択） | A. 床に置いたタブレット／B. スマートフォン |
| Q5 | 遊び中に飼い主だけが操作する方法 | X. ネコはスワイプしないので、スワイプで飼い主の操作と判定する（→ 承認時に「α を描く」に変更） |
| Q6 | 「遊びすぎ」への応え方 | B. 上限は設けない（ネコが飽きて触らなくなったら終わる） |
| Q7 | 飼い主の操作とみなすスワイプ | B. 画面の端から内側へ長くなぞる（→ 承認時に「α を描く」に変更） |
| Q8 | 遊んだ時間の数え方 | C. ネコが最初に触ってから最後に触ったときまで |
| Q9 | 記録を保存できなかったとき | C. 端末に保存して自動で送り直し、失敗が続いたら結果画面とホームで知らせる |

- まとめの確認：Looks correct
- 承認時の変更依頼：飼い主の操作を「端から長くなぞる」から「画面に指で α を描く」に変更（スワイプはタブレットにもともとある操作と区別しにくいため）
