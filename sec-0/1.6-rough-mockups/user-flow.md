# 1.6 rough-mockups：画面の流れ

```
[S1 LOGIN] → [S2 HOME] ──────────────→ [S6 LOG] ─(back)→ [S2 HOME]
                 │(play)
                 ▼
             [S3 PLAY] ─(draw alpha)→ [S4 MENU] ─(back / auto close)→ [S3 PLAY]
                 │                       │(end)
   (no touch for N sec)                  ▼
                 └─────────────→ [S5 RESULT] ─(draw alpha)→ [S2 HOME]
```

| 流れ | 誰が | 手順 | うまくいかないとき |
|---|---|---|---|
| Flow 1：はじめて使う | 飼い主 | S1 →「新規登録はこちら」→ 登録 → S2 | 入力が違う → 理由を表示／通信できない → 再試行ボタン |
| Flow 2：ネコを遊ばせる（いちばん大事） | 飼い主が始め、ネコが遊ぶ（複数でもよい、Q2） | S2「ネコを遊ばせる」→（提案）α の案内 → S3。飼い主は離れてよい。触ると「ビクッ」（Q1）。一定時間触らなければ S5（Q3、上限なし Q6）。遊んだ時間を保存（Q8）。飼い主が α を描いて S2 | なでる・なぞる → 何も起きない／S5 に触る → 何も起きない／保存できない → 端末に保存して自動で送り直し、失敗が続いたら S5 と S2 で知らせる（Q9） |
